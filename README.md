# 四象限分類ツール

任意の2軸を定義し、項目を `-1.0`〜`+1.0` の座標で登録・可視化するローカルWebアプリです。カラオケ、仕事、技術、ゲーム、アイデアなど用途を限定しません。

## 起動方法

- Python 3.10以上（外部Pythonパッケージ不要）
- Windowsでは、リポジトリのルートで `python server.py` を実行します。
- ターミナルに表示される `http://127.0.0.1:8765/` をブラウザーで開きます（既定では自動的に開きます）。
- 停止するにはターミナルで `Ctrl+C` を押します。
- ポートを変える場合は `python server.py --port 9000`、ブラウザーを自動起動しない場合は `python server.py --no-browser` を指定します。

サーバーは既定で `127.0.0.1` のみで待ち受けます。ネットワークへ公開する用途には対応していません。

## 基本操作

1. **設定**タブで設定ID・設定名・X/Y軸のポジティブ/ネガティブ側の名称を登録します。設定IDは英数字で始まる英数字・ハイフン・アンダースコアの1〜64文字です。
2. **データ**タブでデータセットを作成し、使用する設定を選んで保存します。
3. 「項目を追加」から項目名、表示名、画像、X/Y評価、note、tagsを入力します。評価はスライダー・数値入力・小型マップのクリックで指定でき、それぞれ同期します。
4. **マップ**タブでデータセットを選ぶと、軸ラベル付きのマップが表示されます。タグで絞り込み、マップ上または項目一覧から項目を選ぶと詳細を確認できます。

データセット情報の変更は「データセットを保存」で保存します。項目の追加・編集・削除は操作ごとにJSONへ保存されます。設定/データセットIDは作成後に変更できません。評価値0は中立です。

## JSONとファイル保存

データはアプリ起動フォルダー内の `data/` に保存され、設定とデータセットは別ファイルです。

```text
data/
├─ settings/<設定ID>.json
├─ datasets/<データセットID>.json
└─ images/<アップロード画像>
```

設定JSONの例:

```json
{
  "id": "karaoke",
  "name": "カラオケ曲分類",
  "axis_x": { "positive": "好き", "negative": "嫌い" },
  "axis_y": { "positive": "得意", "negative": "苦手" }
}
```

データセットJSONの例:

```json
{
  "id": "karaoke_songs",
  "name": "カラオケ曲",
  "setting": "karaoke",
  "items": [
    {
      "id": "reset-song",
      "name": "Reset",
      "display_name": "Reset",
      "image": null,
      "x": 0.8,
      "y": 0.6,
      "note": "十八番候補",
      "tags": ["ゲーム"]
    }
  ]
}
```

`setting` は設定IDを参照します。各項目には編集時の識別用 `id` も保存されます。`display_name` が空の場合は `name` が表示されます。`image` は `data/images/` からの相対パスまたは `null` です。画像はデータ画面からアップロードしてください（PNG/JPG/GIF/WebP、10MB以下）。外部パスは利用できません。

IDはファイルパスとして安全な形式に制限されています。JSON保存時には座標・必須項目・設定参照・画像の存在を検証します。壊れたJSON、設定参照切れ、見つからない画像は画面上に警告し、アプリ全体は停止しません。読み込めないJSONファイルは修正または退避すると再利用できます。

## テスト

```text
python -m unittest discover -s tests -v
```

## 現在の制限

- 単一ユーザー・単一端末向けのローカルアプリです。クラウド同期、認証、共有、データベースはありません。
- マップ項目の自動配置調整は行いません。同じ座標付近の項目は少しずらして表示し、下部の項目一覧からも選択できます。
- 設定ID・データセットIDの変更、設定/データセット自体の削除、JSONファイルのインポート/エクスポートUIはありません。JSONファイルは `data/` 内でバックアップできます。
- 画像を再アップロードすると新しいファイルが保存されます。参照されなくなった画像ファイルは自動削除されません。
